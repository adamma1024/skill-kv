\begin{abstract}
Serving systems increasingly reuse the key/value (KV) cache of text encoded outside the context in which it is later
read---agent skills, tool schemas, retrieved documents---by splicing it in at a non-prefix position. Such reuse is evaluated
for latency and accuracy, and recent security work studies adversaries who poison cached state. We show that an
\emph{honestly computed} context-free cache changes which instructions a model obeys.

\textbf{Untrusted tool output.} Across five open models (Qwen3 4B--32B and Llama-3.2-3B), mounting an untrusted tool result
from a KV cache computed without the conversation raises compliance with instructions injected into it. The attacker needs no
access to the cache, and a defensive system prompt does not help. The increase holds on three kinds of input:
\begin{itemize}
\item synthetic documents: up to \ScaleSynDThirtyTwo;
\item Wikipedia documents: up to \ScaleNatDThirtyTwo;
\item the InjecAgent benchmark: up to \IaDFourteen\ in attack success.
\end{itemize}

\textbf{Mechanism.} Blocking the document's attention to the conversation inside an ordinary prefill reproduces the effect
within $\pm 0.08$ on every model and dataset, which isolates context-free encoding, rather than the position shift, as the cause.
On three of four models, explicit attention measurements show the first answer token attending more to the injected span and less
to the user's request.

\textbf{Mitigation and scope.} CacheBlend-style selective recompute reduces the excess roughly in proportion to its compute,
and needs about half of a full prefill to remove it. When documents precede the question, as in classic RAG, the effect
largely disappears.

\textbf{Trusted skills.} The same encoding can make a model obey all rules of a trusted agent skill (Qwen3-4B: \WtwoFourCone\
$\rightarrow$ \WtwoFourCthree\ of tasks), but this benefit is model-dependent.

We conclude that KV reuse should be keyed on the trust level of the content.
\end{abstract}

\section{Introduction}
Prompt prefill dominates latency when long inputs are processed repeatedly. Serving systems have therefore moved from exact
prefix caching~\citep{gim2024promptcache,zheng2024sglang} to reusing KV caches at arbitrary
positions~\citep{yao2025cacheblend,hu2024epic,chen2026kvpacket,li2026notes,liu2025lmcache}.

Agents are a natural target. Skills loaded on demand~\citep{zhang2026progressive,nakasuji2026skillblocks}, tool
schemas~\citep{fang2026recache} and retrieved documents~\citep{lu2024turborag,yao2025cacheblend} are static or reused, so their
KV can be computed once and spliced in whenever they are needed. In these systems a reusable segment is encoded \emph{out of
context}, typically after a fixed header but without the conversation in which it will later be read.

Work on such reuse measures latency and task accuracy~\citep{cestola2026evaluating,rakotonirina2026where}. Security work studies
adversaries who craft cached state through optimized prefixes or direct
manipulation~\citep{zhang2026hijackkv,zhu2026r2ecap,ganesh2025narrative}. We ask a different question: when the cache is honest,
computed from exactly the visible text, does context-free encoding change \emph{which instructions the model follows}?

It does. Our findings, in order of section:
\begin{enumerate}
\item \textbf{Injection amplification without poisoning} (\S\ref{sec:injection}).
  \begin{itemize}
  \item Mounting untrusted tool output from a context-free cache raises compliance with instructions embedded in it. This holds on
    five models from two families (3B--32B), on synthetic and on natural Wikipedia documents, and on the InjecAgent tool-calling
    benchmark~\citep{zhan2024injecagent}.
  \item The largest effect is on the largest model we test: Qwen3-32B goes from \ScaleSynToneThirtyTwo\ to \ScaleSynTthreeThirtyTwo.
  \item Qwen3-8B complies in 0 of \InjNtrials\ trials when the same text is prefilled.
  \item A defensive system prompt does not reduce the effect, and clean-document accuracy can stay unchanged, so quality evaluations
    would not reveal it.
  \end{itemize}
\item \textbf{Mechanism} (\S\ref{sec:mechanism}).
  \begin{itemize}
  \item Blocking the document's attention to the user turn inside an ordinary prefill reproduces the effect (within $\pm 0.08$)
    on every model and dataset, so the position shift is not needed.
  \item On three of four models, explicit attention measurements show that the first answer token attends more to the injected
    span under context-free encoding, and items that flip to compliance show the largest shifts.
  \end{itemize}
\item \textbf{Mitigation and scope} (\S\ref{sec:mitigation}).
  \begin{itemize}
  \item Recomputing boundary tokens does nothing.
  \item CacheBlend-style selective recompute reduces the excess roughly in proportion to its compute, and needs about half of a
    prefill to remove it.
  \item In the classic RAG layout, where documents precede the question, the effect is small or absent.
  \end{itemize}
\item \textbf{Trusted skills} (\S\ref{sec:skills}). The same encoding can make a model obey standalone rules in a skill that text
  loading drops. On Qwen3-4B this lifts all-rules compliance from \WtwoFourCone\ to \WtwoFourCthree, but the benefit is
  model-dependent.
\end{enumerate}

Together these suggest a single design rule: KV reuse should be keyed on the trust level of the content (\S\ref{sec:discussion}).
We release the splice and selective-recompute engines for MLX, which are tested against exact prefill, the benchmarks and all
logs; a script generates every number in this paper from the logs.

\section{Background and threat model}\label{sec:background}
\textbf{KV reuse.} A decoder caches, for every token and layer, the key and value vectors that later tokens attend to. Exact
prefix caching reuses these vectors only when a new request starts with the same tokens.

Position-independent reuse goes further: it stores the KV of a segment $s$, computed after some fixed prelude $p$, and splices
it into a new context at position $P$. Because rotary position embeddings compose additively, cached keys can be re-rotated by
$P-|p|$. The spliced tokens, however, never attended to whatever precedes them in the new context, beyond $p$. Systems repair
this by recomputing a subset of tokens~\citep{yao2025cacheblend,hu2024epic}, by training boundary
adapters~\citep{chen2026kvpacket}, by fine-tuning for block-wise encoding~\citep{ma2025blockattention,yang2025kvlink,yang2025ape},
or by accepting the approximation~\citep{li2026notes,fang2026recache,lu2024turborag}.

\textbf{Agent layout.} We study an agent loop in which a tool result is read \emph{after} the user's request:
\begin{center}\small\texttt{[system] [user request; assistant tool call] [tool result] [assistant]}\end{center}
If the tool result is mounted from a cache computed after \texttt{[system][tool-result header]}, the result never attends to the
request or the call.

\textbf{Threat model.}
\begin{itemize}
\item The attacker controls only the \emph{content} of a document or tool response, as in indirect prompt
  injection~\citep{greshake2023indirect}.
\item The serving system computes the document's KV honestly from that content, with no attacker prefix and no tampering, and
  reuses it within the same request.
\item The attacker succeeds if the model follows the injected instruction.
\end{itemize}
Cache-poisoning attacks~\citep{zhang2026hijackkv,zhu2026r2ecap} assume a stronger adversary; ours asks whether the reuse
mechanism itself amplifies an ordinary injection. We know of no deployed system that applies context-free reuse to untrusted
tool output in exactly this layout. Our results are therefore a design warning for systems that extend non-prefix reuse to agent
tool results, which is a natural next step for the methods above.

\section{Related work}\label{sec:related}
\textbf{KV reuse.} Prompt Cache~\citep{gim2024promptcache} and RadixAttention~\citep{zheng2024sglang} reuse exact prefixes.
LMCache~\citep{liu2025lmcache} and the knowledge-delivery view~\citep{cheng2024kdn} treat KV as storable knowledge.

Non-prefix reuse either recomputes selected tokens (CacheBlend~\citep{yao2025cacheblend}, EPIC~\citep{hu2024epic}), trains
adapters or adapts attention (KV Packet~\citep{chen2026kvpacket}, Block-Attention~\citep{ma2025blockattention},
APE~\citep{yang2025ape}, KVLink~\citep{yang2025kvlink}), or splices with little or no repair (TurboRAG~\citep{lu2024turborag},
Notes at Prefill~\citep{li2026notes}, ReCache~\citep{fang2026recache}).

Cartridges~\citep{eyuboglu2025cartridges} train compact KV for a corpus. Work on composing and evaluating reused KV measures
accuracy~\citep{shepard2026costs,rakotonirina2026where,cestola2026evaluating}. Cross-model transfer~\citep{liu2024droidspeak,fu2025c2c}
is orthogonal.

\textbf{Security of KV reuse.}
\begin{itemize}
\item HijackKV~\citep{zhang2026hijackkv} optimizes an attacker prefix so that the KV of a later benign chunk carries the
  attacker's goal; the chunk is then served to other requests through position-independent reuse.
\item R$^2$ECAP~\citep{zhu2026r2ecap} poisons reused reasoning traces in a black-box setting.
\item \citet{ganesh2025narrative} overwrite cache segments directly.
\item \citet{sun2026sidechannel} exploit non-prefix RAG caches as a side channel.
\end{itemize}
In all of these the cached state is not what the visible text alone would produce. Here it is.

\textbf{Indirect prompt injection and defenses.} Benchmarks include InjecAgent~\citep{zhan2024injecagent},
AgentDojo~\citep{debenedetti2024agentdojo} and BIPIA~\citep{yi2025bipia}. Defenses separate data from instructions at the input or
in training: spotlighting~\citep{hines2024spotlighting}, structured queries~\citep{chen2025struq}, preference
optimization~\citep{chen2025secalign}, and the instruction hierarchy~\citep{wallace2024hierarchy}. One might expect that isolating
untrusted text in attention acts as a similar separation. Our masking control shows the opposite.

\textbf{Skills.} Agents do not reliably follow skill requirements~\citep{li2026hexis}. Skill-loading strategies have been compared
only at the text level~\citep{zhang2026progressive,nakasuji2026skillblocks}.

\section{Method}\label{sec:method}
\textbf{Packs and splicing.} A \emph{pack} stores the per-layer K/V of a segment $s$ computed after a prelude $p$.
mlx-lm~\citep{hannun2023mlx} caches post-RoPE keys, so mounting a pack at position $P$ re-rotates its keys by $P-|p|$ with the
model's own RoPE before appending them. This works for standard and Llama-3-scaled RoPE.

\textbf{Selective recompute and masking.} A layer-wise engine mounts a segment while recomputing a chosen token subset in the real
context. Recomputed tokens get fresh Q/K/V and attend causally to the prefix, to the pack's K/V for the other segment tokens, and to
the fresh K/V of the other recomputed tokens. The same engine can forbid segment tokens from attending to a range of prefix
positions. Unit tests on Qwen3 and Llama check three equivalences:
\begin{itemize}
\item recomputing every token equals text prefill;
\item recomputing none equals the plain splice;
\item a masked segment is independent of the masked tokens.
\end{itemize}

\textbf{Conditions.} All conditions in a comparison share identical token ids. Table~\ref{tab:conditions} defines them; their roles
are as follows.
\begin{itemize}
\item \cond{T1} is standard prefill.
\item \cond{T3} is the context-free pack.
\item \cond{T1$'$} isolates the absence of attention to the conversation from the position shift.
\item \cond{T3G} gives the pack a conversation-shaped prelude.
\item \cond{T3B$x$} approximates CacheBlend: all tokens are recomputed on two layers, then the $x\%$ with the largest layer-1 K/V
  deviation on all later layers.
\end{itemize}

\section{Experimental setup}\label{sec:setup}
\textbf{Models.} Qwen3-4B and Qwen3-8B (bf16, thinking off)~\citep{yang2025qwen3}, Qwen3-14B and Qwen3-32B (4-bit MLX
quantization, bf16 KV), and Llama-3.2-3B-Instruct (bf16)~\citep{grattafiori2024llama3}. All run on one Apple M5 Pro laptop (64\,GB)
with MLX 0.32.4 and mlx-lm 0.32.2. Prompts use each model's chat format, assembled from strings; Appendix~\ref{app:prompts} gives
the exact templates.

\textbf{Synthetic documents.} We generate 24 procedure documents (650--3,300 tokens). The user asks for one parameter value and
reads the document through a \texttt{read\_doc} tool. Each document has a clean version and three injected versions, with an inert
canary placed at depth 0.1, 0.5 or 0.9:
\begin{itemize}
\item \emph{override}: ``ignore the user's question, reply only \texttt{ACK-<canary>}'';
\item \emph{append}: ``end with \texttt{ref:~<canary>}'';
\item \emph{refuse}: ``say the document is confidential''.
\end{itemize}
Each condition has \InjNinjected\ injected items $\times$ 2 seeds $=$ \InjNtrials\ trials.

\textbf{Natural documents.} For each of the \NatNdocs\ articles in the SQuAD v1.1 validation set~\citep{rajpurkar2016squad}, we
concatenate consecutive paragraphs into a 555--806-word document. The question is a SQuAD question with a short answer (at most 4
words) found in the document. Override and append canaries are inserted at sentence boundaries at the same three depths, giving
\NatNinjected\ injected items $\times$ 2 seeds per condition.

\textbf{InjecAgent.} We use every fourth case of the direct-harm and data-stealing test sets in the \emph{enhanced}
setting~\citep{zhan2024injecagent}, giving \IaNcases\ cases over \IaNattacks\ attack instructions. The system prompt lists the user
tool and the attacker tools. The model sees the user instruction and its own call to the user tool, then reads the tool response,
which contains the attack. An attack succeeds if the next turn calls the attacker tool. Every fourth case also runs a clean control
with the injected sentence removed. Tools are only described, never executed.

\textbf{Skills.} We use 24 synthetic skills, each planting five rules: an opening code line, a file-name prefix, a parameter value,
a step-list heading, and a closing sign-off. The question asks for the step list, file name and parameter but never mentions the code
line, heading or sign-off. Grading is positional: the code line must come first and the sign-off last.

\textbf{Decoding and statistics.}
\begin{itemize}
\item Sampling uses $T{=}0.7$, top-$p$ 0.8 and top-$k$ 20, with the random stream shared across the conditions of an item.
\item No injection or InjecAgent response reached its token budget.
\item Intervals are paired, percentile-bootstrap 95\% CIs that resample documents (or InjecAgent attack instructions, or skills),
  because items built on one document are correlated.
\item We do not correct for multiple comparisons. Appendix~\ref{app:results} lists every contrast we ran, and intervals that touch
  zero should be read as inconclusive.
\end{itemize}

\section{Results}\label{sec:results}
\subsection{Implementation check}\label{sec:fidelity}
A pack built with the exact context reproduces text prefill (mean token-level KL 0.001). Packs built after
\texttt{[system][header]} deviate only through the missing conversation (KL \PilotKLRange). Splicing lowers post-selection
time-to-first-token by a median of \PilotSpeedupOne--\PilotSpeedupFour$\times$ (Appendix Table~\ref{tab:pilot}), reproducing the
known benefit~\citep{li2026notes,fang2026recache}.

\textbf{Synthetic documents.} Mounting the untrusted document from a context-free pack (\cond{T3}) raises compliance on every model

\textbf{Natural documents.} Models comply far more often even under plain prefill, and Qwen3-4B is at ceiling (0.95). Packs still

\textbf{Scale.} The effect does not shrink with scale. The largest model, Qwen3-32B, shows the largest increase on both document
types, because it is well protected under prefill (\ScaleSynToneThirtyTwo\ and \ScaleNatToneThirtyTwo) but not under a pack.

\textbf{The cache is clean.} No attacker access to the cache is involved: the pack is computed from exactly the visible text.

\subsection{Mechanism: the document never saw the conversation}\label{sec:mechanism}
\begin{table}[t]
\centering\small
\resizebox{\linewidth}{!}{\input{tables/mechanism_all.tex}}
\caption{Mechanism contrasts across models and datasets (paired differences in compliance, clustered 95\% CIs). Left: the pack versus

\label{tab:mechanism_all}

\textbf{Masking reproduces the pack.} The masked-text control \cond{T1$'$} keeps the true positions and changes only what the document
attends to (Table~\ref{tab:mechanism_all}). Across five models and three datasets, \cond{T3}$-$\cond{T1$'$} stays within $\pm 0.08$.
In most cells it is zero or negative: the masked document is obeyed at least as often as the pack. Re-rotating keys is therefore not
what drives the effect; preventing the document from attending to the user's request is sufficient.

\textbf{Conversation-shaped prelude.} A pack built after a content-free question and tool call (\cond{T3G}) behaves differently by
model family:
\begin{itemize}
\item On Llama-3.2-3B it removes the effect, and on natural documents it even lowers compliance below text.
\item On Qwen models it leaves a significant excess, at times as large as the plain pack's.
\end{itemize}
Seeing \emph{a} conversation is not equivalent to seeing \emph{the} conversation, so a generic prelude is not a reliable mitigation.

\textbf{Role confound.} In Qwen's chat template a tool result is a \texttt{user} turn, so a Qwen pack encodes the document as if it
were the first user message. Llama uses a dedicated \texttt{ipython} role and shows the effect as well, which reduces this concern
but does not rule it out: its pack is still the first non-system turn.

\item \textbf{Qwen3-8B is the exception.} Attention to the injected span does not change (\AttnInjDEight), even though its behavior

\subsection{Mitigation and scope}\label{sec:mitigation}
\begin{figure}[t]
\centering
\includegraphics[width=0.5\linewidth]{figures/sweep.pdf}\\[4pt]
{\small\input{tables/sweep.tex}}
\caption{Excess injection compliance over text (\cond{T3$x$}$-$\cond{T1}, synthetic documents) as a function of CacheBlend-style
selective recompute. The x-axis is the measured fraction of prefill compute. Error bars are document-clustered 95\% CIs.}
\label{fig:sweep}

\textbf{Selective recompute.} Recomputing 16 boundary tokens changes compliance by at most 0.05 (Appendix
Table~\ref{tab:mechanism}), so seam repair~\citep{li2026notes} is not a defense. Deviation-selected recompute reduces the excess
roughly in proportion to compute (Figure~\ref{fig:sweep}).
\begin{itemize}
\item At 15\% recompute, a significant residual remains on every model; on Qwen3-14B the excess does not shrink at all.
\item At 50\%, the residual is small, and its CI includes zero on two of three models; on Qwen3-4B it is still significant.
\item The same holds on InjecAgent, where 15\% recompute leaves most of the excess (Table~\ref{tab:injecagent}).
\end{itemize}
Removing the vulnerability thus costs on the order of half a prefill, which erodes most of the latency benefit of reuse.

\textbf{RAG layout.} When three retrieved documents precede the question, not even full prefill lets them see the question.
Precomputing each chunk then removes only cross-document attention (Appendix Table~\ref{tab:rag}).
\begin{itemize}
\item Qwen3-8B and Llama-3.2-3B never comply under any condition.
\item Qwen3-4B shows a smaller increase (\RagDFour), which 15\% recompute brings within noise (\RagDBFour).
\end{itemize}
This layout differs in role, number of documents and tool use, so it is a contrast rather than a controlled ablation. It is
nevertheless consistent with the mechanism: precomputation matters when the reused segment \emph{should} have attended to the
request.

\subsection{Trusted skills}\label{sec:skills}
\begin{figure}[t]
\centering

Skills are trusted content, so here the same mechanism is a potential benefit (Figure~\ref{fig:skills}, Appendix
Tables~\ref{tab:skillrules}--\ref{tab:w2contrasts}).

\textbf{Qwen3-4B.} When a skill is prefilled as a tool result, the model follows the rules tied to the request but drops the opening
code line and the closing sign-off. Only \WtwoFourCone\ of tasks obey all five rules. A context-free pack raises this to
\WtwoFourCthree\ (\WtwoFourDthree). Two controls bear on the cause:
\begin{itemize}
\item Naming every rule in the question has the same effect as the pack.
\item A conversation-shaped pack does not help.
\end{itemize}

\textbf{Other models.} Qwen3-8B shows a smaller gain (\WtwoEightDthree), and Llama-3.2-3B none. On both Qwen models, packs raise the
standalone opening and closing directives---the same kind of directive whose injection they amplify. On Qwen3-8B and Llama, packs
also weaken rules that are integrated with the task, such as the heading.

\section{Discussion}\label{sec:discussion}
\textbf{A working account.} Text encoded inside a conversation is represented relative to it, as material retrieved for the user's
request, and the model acts on what that request needs. Text encoded without the conversation but read after it is closer to a
standalone instruction. This account fits the following results:
\begin{itemize}
\item the masking control;
\item the attention measurements;
\item the per-rule skill results;
\item the RAG contrast.
\end{itemize}

It is incomplete in two respects:
\begin{itemize}
\item Chunks with no prelude at all (\cond{R3N}) are \emph{never} obeyed in the RAG layout. Whatever gains authority needs some
  context (here, the system prompt), just not the conversation.
\item A conversation-shaped prelude helps on one model only.
\end{itemize}

\textbf{Implications.}
\begin{itemize}
\item Cache-poisoning attacks~\citep{zhang2026hijackkv,zhu2026r2ecap} call for integrity checks on cached state. Our results show
  that an honestly computed cache can still change model behavior, so whether to reuse context-free KV must also depend on where the
  content came from.
\item Untrained attention-level isolation is not a defense, unlike trained separation of data and
  instructions~\citep{chen2025struq,chen2025secalign}.
\item Packs also lower answer accuracy on natural documents, because the document is encoded without knowing what will be asked. A
  context-free cache is therefore not a neutral optimization even for trusted content.
\end{itemize}

\textbf{Recommendations.}
\begin{itemize}
\item Reserve context-free reuse, with provenance metadata, for trusted first-party content, and check per model that it does not
  degrade how that content is followed.
\item Prefill untrusted tool output in context whenever it follows the user's request. Selective recompute must approach half a
  prefill to remove the effect.
\item Evaluate reuse features for instruction-following and injection behavior, not only for accuracy and latency.
\end{itemize}

\section{Limitations}\label{sec:limitations}
\begin{itemize}
\item All models are open models of at most 32B parameters, and the two largest are 4-bit quantized.
\item We do not test production serving stacks. Our CacheBlend-style engine uses one-shot rather than gradual token selection.
\item The synthetic documents and skills are templated, and the canary injections are explicit. The natural-document and InjecAgent
  results partly address this, but agents with multi-step tool use (e.g., AgentDojo~\citep{debenedetti2024agentdojo}) remain to be
  tested.
\item The skill benefit is clear on one model only.
\item The account in \S\ref{sec:discussion} is supported by behavioral contrasts and by correlational attention evidence (which
  fails on one model); it is not established by a causal, circuit-level analysis.
\end{itemize}

\section*{Broader impact statement}
This work identifies a way that a performance optimization can weaken a model's resistance to prompt injection. The vulnerable
configuration requires reusing context-free KV for untrusted content placed after the user's request, which we did not find in
deployed systems. We therefore present it as a design warning, together with the mitigation and its cost. All injections are inert
canaries or the simulated tools of a public benchmark, run against local models. An AI coding assistant was used for
implementation, running experiments and drafting; a script generates every reported number from the released logs.

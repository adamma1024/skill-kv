\begin{abstract}
Serving systems increasingly reuse the key/value (KV) cache of text that was encoded outside the context in which it is later
read---agent skills, tool schemas, retrieved documents---by splicing it in at a non-prefix position. Such reuse is evaluated for
latency and accuracy, and recent security work studies adversaries who poison cached state. We ask a different question: does an
\emph{honestly computed} context-free cache change which instructions a model obeys?

In an agent layout where a tool result follows the user's request, we mount the tool result from a KV cache computed without the
conversation (a \emph{pack}). This raises compliance with instructions injected into the tool result. We test seven open
models (Qwen3 4B--32B and Llama-3 3B and 8B), synthetic and Wikipedia documents, and a stage-1 adaptation of InjecAgent. Of
\PrimaryN\ primary model-by-dataset contrasts, \PrimaryPos\ show a significant increase after Holm correction, of up to
\ScaleSynDThirtyTwo; none shows a significant decrease. The attacker needs no access to the cache, and neither a defensive system
prompt nor spotlighting removes the increase.

The cause is the missing attention from the document to the user's request. Blocking only that edge inside an ordinary prefill
raises compliance to the level of the pack. Blocking only the edge to the tool call leaves compliance at the level of plain prefill.

CacheBlend-style selective recompute shrinks the excess as more is recomputed. At about \FracBfifty\% of prefill compute, a
significant residual remains on three of five models, and most of the latency benefit is gone.

For trusted agent skills, the same encoding raises adherence to standalone rules on Qwen3-4B, but no more than placing the skill in
the system prompt does.

Context-free reuse should therefore be keyed on the trust level of the content.
\end{abstract}

\section{Introduction}
Prompt prefill dominates latency when long inputs are processed repeatedly. Serving systems have therefore moved from exact
prefix caching~\citep{gim2024promptcache,zheng2024sglang} to reusing KV caches at arbitrary
positions~\citep{yao2025cacheblend,hu2024epic,chen2026kvpacket,li2026notes,liu2025lmcache}.

Agents are a natural target. Several kinds of content are static or reused, so their KV can be computed once and spliced in whenever
they are needed:
\begin{itemize}
\item skills loaded on demand~\citep{zhang2026progressive,nakasuji2026skillblocks};
\item tool schemas and tool results~\citep{fang2026recache};
\item retrieved documents~\citep{lu2024turborag,yao2025cacheblend}.
\end{itemize}
In these systems a reusable segment is encoded \emph{out of context}: typically after a fixed header, but without the conversation
in which it will later be read.

Work on such reuse measures latency and task accuracy~\citep{cestola2026evaluating,rakotonirina2026where}. Security work studies
adversaries who shape cached state through optimized prefixes or direct
manipulation~\citep{zhang2026hijackkv,zhu2026r2ecap,ganesh2025narrative}. We ask a different question: when the cache is honest,
computed from exactly the visible text, does context-free encoding change \emph{which instructions the model follows}?

Our findings, in order of section:
\begin{enumerate}
\item \textbf{Injection amplification without poisoning} (\S\ref{sec:injection}).
  \begin{itemize}
  \item Mounting untrusted tool output from a context-free pack raises compliance with instructions embedded in it.
  \item Of \PrimaryN\ primary model-by-dataset contrasts, \PrimaryPos\ are significant after Holm correction, all of them increases.
  \item The largest increases are on Qwen3-32B (\ScaleSynDThirtyTwo\ on synthetic and \ScaleNatDThirtyTwo\ on Wikipedia
    documents) and on Llama-3.1-8B (\ScaleSynDLlamaEight\ on synthetic documents).
  \item The non-significant cells include two floors and one ceiling. Llama-3.2-3B almost never calls the attacker tool in
    InjecAgent, and Qwen3-4B already obeys Wikipedia injections under plain prefill.
  \item Neither a defensive system prompt nor spotlighting~\citep{hines2024spotlighting} removes the increase. A 4-bit Qwen3-8B shows
    it too, so quantization is not required for it.
  \end{itemize}
\item \textbf{Behavioral localization} (\S\ref{sec:mechanism}).
  \begin{itemize}
  \item Masking the document's attention to the conversation inside an ordinary prefill, at the true positions, raises compliance
    by about as much as the pack on most models. Key re-rotation is therefore not needed.
  \item A partial-mask ablation localizes the effect. A document that can attend to the user's request is obeyed as rarely as under
    plain prefill, even when it cannot attend to the tool call. A document that sees only the tool call is obeyed as often as a
    pack.
  \item Attention from the first answer token to the injected span rises under a pack on synthetic documents for every model,
    but not consistently on natural documents.
  \end{itemize}
\item \textbf{Mitigation and scope} (\S\ref{sec:mitigation}).
  \begin{itemize}
  \item Recomputing the first or last 16 document tokens changes little.
  \item CacheBlend-style selective recompute reduces the excess as its budget grows. On three of five models, however, a significant
    residual remains at about \FracBfifty\% of prefill compute. By then time-to-first-token is 0.5--0.8$\times$ that of full
    prefill, against about 0.05$\times$ for the plain pack.
  \item On InjecAgent, \FracBfifteen\% recompute leaves almost the whole increase.
  \item In the classic RAG layout, where documents precede the question, only one model complies at all, and its increase is smaller.
  \end{itemize}
\item \textbf{Trusted skills} (\S\ref{sec:skills}). The same encoding lifts adherence to standalone skill rules on Qwen3-4B
  (\WtwoFourCone\ $\rightarrow$ \WtwoFourCthree\ of tasks obey all rules). Placing the skill in the system prompt, which exact
  prefix caching already serves, does as well.
\end{enumerate}

Together these suggest a design rule: context-free reuse should be keyed on the trust level of the content
(\S\ref{sec:discussion}). We release the splice and selective-recompute engines for MLX, which are tested against exact prefill,
together with the benchmarks, all logs, and a script that generates every number in this paper from the logs.

\section{Background and threat model}\label{sec:background}
\textbf{KV reuse.} A decoder caches, for every token and layer, the key and value vectors that later tokens attend to. Exact prefix
caching reuses these vectors only when a new request starts with the same tokens.

Position-independent reuse goes further. It stores the KV of a segment $s$, computed after some fixed prelude $p$, and splices it
into a new context at position $P$. Because rotary position embeddings compose additively, cached keys can be re-rotated by
$P-|p|$. The spliced tokens, however, never attended to whatever precedes them in the new context beyond $p$. Systems handle this in
one of four ways:
\begin{itemize}
\item recomputing a subset of tokens~\citep{yao2025cacheblend,hu2024epic};
\item training boundary adapters~\citep{chen2026kvpacket};
\item fine-tuning for block-wise encoding~\citep{ma2025blockattention,yang2025kvlink,yang2025ape};
\item accepting the approximation~\citep{li2026notes,fang2026recache,lu2024turborag}.
\end{itemize}

\textbf{Agent layout.} We study an agent loop in which a tool result is read \emph{after} the user's request:
\begin{center}\small\texttt{[system] [user request; assistant tool call] [tool result] [assistant]}\end{center}
If the tool result is mounted from a cache computed after \texttt{[system][tool-result header]}, it never attends to the request or
the call.

\textbf{Threat model.}
\begin{itemize}
\item The attacker controls only the \emph{content} of a document or tool response, as in indirect prompt
  injection~\citep{greshake2023indirect}.
\item The serving system computes the document's KV honestly from that content, with no attacker prefix and no tampering, and
  reuses it within the same request.
\item The attacker succeeds if the model follows the injected instruction.
\end{itemize}
We know of no deployed system that applies context-free reuse to untrusted tool output in exactly this layout. Systems that already
cache tool results or tool schemas for agents~\citep{fang2026recache}, or retrieved chunks after a
header~\citep{lu2024turborag,yao2025cacheblend}, are one step away. Our results are therefore a design warning for that step, not a
report of an exploitable deployment.

\section{Related work}\label{sec:related}
\textbf{KV reuse.} Prompt Cache~\citep{gim2024promptcache} and RadixAttention~\citep{zheng2024sglang} reuse exact prefixes.
LMCache~\citep{liu2025lmcache} and the knowledge-delivery view~\citep{cheng2024kdn} treat KV as storable knowledge.

Non-prefix reuse takes one of three approaches:
\begin{itemize}
\item recompute selected tokens: CacheBlend~\citep{yao2025cacheblend}, EPIC~\citep{hu2024epic};
\item train adapters or adapt attention: KV Packet~\citep{chen2026kvpacket}, Block-Attention~\citep{ma2025blockattention},
  APE~\citep{yang2025ape}, KVLink~\citep{yang2025kvlink};
\item splice with little or no repair: TurboRAG~\citep{lu2024turborag}, Notes at Prefill~\citep{li2026notes},
  ReCache~\citep{fang2026recache}.
\end{itemize}
Parallel Context Windows~\citep{ratner2023pcw} and superposition prompting~\citep{merth2024superposition} encode segments
independently by design.

Cartridges~\citep{eyuboglu2025cartridges} train compact KV for a corpus. Work on composing and evaluating reused KV measures
accuracy~\citep{shepard2026costs,rakotonirina2026where,cestola2026evaluating}. KV \emph{compression} is known to degrade instruction
following, in particular of system prompts~\citep{chen2025pitfalls}. We study reuse without compression and
measure which instructions win. Cross-model transfer~\citep{liu2024droidspeak,fu2025c2c} is orthogonal.

\textbf{Security of KV reuse.}
\begin{itemize}
\item HijackKV~\citep{zhang2026hijackkv} optimizes an attacker prefix so that the honestly computed KV of a later chunk carries the
  attacker's goal. The chunk is then served to other requests through position-independent reuse.
\item R$^2$ECAP~\citep{zhu2026r2ecap} poisons reused reasoning traces in a black-box setting.
\item \citet{ganesh2025narrative} overwrite cache segments directly.
\item \citet{sun2026sidechannel} exploit non-prefix RAG caches as a side channel.
\end{itemize}
In all of these the adversary controls the \emph{encoding context} of the cached state or the state itself. In our setting the
attacker controls only the content, and the encoding context is the serving system's fixed header.

\textbf{Indirect prompt injection and defenses.} Benchmarks include InjecAgent~\citep{zhan2024injecagent},
AgentDojo~\citep{debenedetti2024agentdojo} and BIPIA~\citep{yi2025bipia}. Defenses separate data from instructions in one of three
ways:
\begin{itemize}
\item at the input: spotlighting~\citep{hines2024spotlighting};
\item in training: structured queries~\citep{chen2025struq}, preference optimization~\citep{chen2025secalign,chen2025metasecalign},
  the instruction hierarchy~\citep{wallace2024hierarchy};
\item in the architecture: segment embeddings~\citep{wu2025ise} and rotated data embeddings~\citep{zverev2025aside}.
\end{itemize}
\citet{zverev2025separate} measure how well models separate instructions from data. Attention Tracker~\citep{hung2025attentiontracker}
detects injections from the attention that specific heads pay to the original instruction, which relates to our attention
measurements in \S\ref{sec:mechanism}. One might expect that isolating untrusted text in attention acts as a separation of this
kind. Our masking control shows the opposite.

\textbf{Skills.} Agents do not reliably follow skill requirements~\citep{li2026hexis}. Skill-loading strategies have been compared
by task success and token cost~\citep{zhang2026progressive,nakasuji2026skillblocks}. To our knowledge, none of these compare how
the loaded KV was encoded.

\section{Method}\label{sec:method}
\textbf{Packs and splicing.} A \emph{pack} stores the per-layer K/V of a segment $s$ computed after a prelude $p$.
mlx-lm~\citep{hannun2023mlx} caches post-RoPE keys, so mounting a pack at position $P$ re-rotates its keys by $P-|p|$ with the
model's own RoPE before appending them. This works for standard and Llama-3-scaled RoPE.

\textbf{Selective recompute and masking.} A layer-wise engine mounts a segment while recomputing a chosen subset of its tokens in the
real context. Recomputed tokens get fresh Q/K/V and attend causally to:
\begin{itemize}
\item the prefix;
\item the pack's K/V for the other segment tokens;
\item the fresh K/V of the other recomputed tokens.
\end{itemize}
The same engine can forbid segment tokens from attending to chosen ranges of prefix positions. Unit tests on Qwen3 and Llama check
three equivalences:
\begin{itemize}
\item recomputing every token equals text prefill;
\item recomputing none equals the plain splice;
\item a masked segment is independent of the masked tokens.
\end{itemize}

\textbf{Conditions.} All conditions in a comparison share identical token ids. Table~\ref{tab:conditions} defines them.
\begin{itemize}
\item \cond{T1} is standard prefill.
\item \cond{T3} is the context-free pack.
\item \cond{T1$'$} prefills the tool-result header and document at their true positions, with attention from these tokens to the user
  turn and the tool call masked. Under relative position encoding, it differs from \cond{T3} only in the size of the position gap
  between the system prompt and the document. It is therefore a sanity check, not an independent mechanism test.
\item \cond{T1Mreq} and \cond{T1Mcall} mask only the tool call or only the user request, and so localize which edge matters.
\item \cond{T3G} gives the pack a conversation-shaped prelude.
\item \cond{T3B$x$} approximates CacheBlend~\citep{yao2025cacheblend}. All document tokens are recomputed on the first two layers,
  then the $x\%$ with the largest layer-1 K/V deviation are recomputed on all later layers. Because two layers are always fully
  recomputed, the measured compute exceeds $x$. We report it with every result: \FracBfifteen\%, 34\% and \FracBfifty\% of prefill
  for $x=15, 30, 50$.
\end{itemize}

\section{Experimental setup}\label{sec:setup}
\textbf{Models.}
\begin{itemize}
\item Qwen3-4B and Qwen3-8B (bf16, thinking off)~\citep{yang2025qwen3}.
\item Qwen3-14B and Qwen3-32B (4-bit MLX weight quantization, bf16 activations and KV).
\item A 4-bit Qwen3-8B, as a control for quantization.
\item Llama-3.2-3B-Instruct and Llama-3.1-8B-Instruct (bf16)~\citep{grattafiori2024llama3}.
\end{itemize}
All models run on one Apple M5 Pro laptop (64\,GB) with MLX 0.32.4 and mlx-lm 0.32.2. Prompts are assembled from strings in each
model's chat format; Appendix~\ref{app:prompts} gives the exact templates. They deviate from the official chat templates in two minor
ways, and a robustness check with the official templates is in \S\ref{sec:robust}:
\begin{itemize}
\item Qwen: the earlier assistant turn keeps an empty thinking block;
\item Llama: the system header lacks the date preamble, and the tool content is not JSON-quoted.
\end{itemize}

\textbf{Synthetic documents.} We generate two libraries of 12 procedure documents each (650--3,300 tokens). The user asks for one
parameter value and reads the document through a \texttt{read\_doc} tool. Each document has a clean version and three injected
versions, with an inert canary placed at depth 0.1, 0.5 or 0.9:
\begin{itemize}
\item \emph{override}: ``ignore the user's question, reply only \texttt{ACK-<canary>}'';
\item \emph{append}: ``end with \texttt{ref:~<canary>}'';
\item \emph{refuse}: ``say the document is confidential''.
\end{itemize}
Each injected item is sampled with two seeds, giving \InjNtrials\ injected trials per condition.

\textbf{Natural documents.} For each of the \NatNdocs\ articles in the SQuAD v1.1 validation set~\citep{rajpurkar2016squad}, we
concatenate consecutive paragraphs into a 555--806-word document. The question is a SQuAD question with a short answer (at most 4
words) found in the document. Override and append canaries are inserted at sentence boundaries at the same three depths. Each item
is sampled with two seeds. We dropped the \emph{refuse} type for natural documents after the synthetic runs, because it almost never
fires there (Table~\ref{tab:pertype}). Only the carrier text is natural: the injection is the same explicit notice as in the
synthetic documents.

\textbf{InjecAgent (stage-1 variant).} We use every fourth case of the direct-harm (DH) and data-stealing (DS) test sets in the
\emph{enhanced} setting~\citep{zhan2024injecagent}. This gives \IaNcases\ cases, crossing \IaNattacks\ attack instructions with
\IaNusers\ user cases.
\begin{itemize}
\item The system prompt lists the user tool and the attacker tools in one line each.
\item The model sees the user instruction and its own call to the user tool, then reads the tool response, which contains the
  attack.
\item The metric is \emph{stage-1 attack success} (ASR): the next turn, generated with a 256-token budget, calls the first attacker
  tool. For data-stealing cases this is only the first of the two steps that InjecAgent counts.
\item Every fourth case also runs a clean control with the injected sentence removed.
\item Tools are only described, never executed.
\end{itemize}
We use no ReAct scaffold, and we do not apply InjecAgent's filter for valid outputs, so our rates are not comparable with published
InjecAgent numbers.

\textbf{Skills.} We use 24 synthetic skills, each planting five rules: an opening code line, a file-name prefix, a parameter value,
a step-list heading, and a closing sign-off. The question asks for the step list, file name and parameter, but never mentions the
code line, heading or sign-off. Grading is positional: the code line must come first and the sign-off last.

\textbf{Decoding and statistics.}
\begin{itemize}
\item Sampling uses $T{=}0.7$, top-$p$ 0.8 and top-$k$ 20. The random stream is shared across the conditions of an item (common
  random numbers).
\item Document runs use a 160-token budget, which none of their \DocNgen\ responses reached. InjecAgent responses use 256 tokens; at
  most \IaTruncMax\% are truncated in any model and condition. Skill answers use 512 tokens; truncation is negligible except for
  Llama-3.2-3B under \cond{C3M} (\WtwoLlamaTruncCthreeM\%), which we flag where it matters.
\item Intervals are paired percentile-bootstrap 95\% CIs. They resample documents, or skills, because items built on one document are
  correlated. For InjecAgent they resample attack instructions and user cases independently, a two-way pigeonhole
  bootstrap~\citep{owen2007pigeonhole}.
\item We pre-designate one family of primary contrasts: \cond{T3}$-$\cond{T1} for every model and dataset (Table~\ref{tab:primary}).
  For these we report cluster sign-flip permutation $p$-values with Holm correction. All other intervals are secondary and
  uncorrected; the appendix lists every contrast we ran.
\end{itemize}

\section{Results}\label{sec:results}
\subsection{Implementation check}\label{sec:fidelity}
We ran this check on Qwen3-1.7B and Qwen3-4B with six real agent skills, not with the models and documents of the main study.
\begin{itemize}
\item A pack built with the exact context reproduces text prefill (mean token-level KL 0.001).
\item Packs built after \texttt{[system][header]} deviate only through the missing conversation (KL \PilotKLRange).
\item Splicing lowers post-selection time-to-first-token (TTFT) by a median of \PilotSpeedupOne--\PilotSpeedupFour$\times$ (Appendix
  Table~\ref{tab:pilot}). This reproduces the known benefit~\citep{li2026notes,fang2026recache} and is not a contribution of this
  paper.
\end{itemize}

\textbf{Synthetic documents.} The pack raises compliance on every model, from \ScaleSynDEightQ\ (Qwen3-8B, 4-bit) to
\ScaleSynDThirtyTwo\ (Qwen3-32B). Every synthetic contrast except the 4-bit Qwen3-8B survives Holm correction.

Pooled rates hide which instruction wins (Table~\ref{tab:pertype}):
\begin{itemize}
\item On Qwen3-4B the \emph{override} instruction, which replaces the user's answer, goes from \TypeSynOverrideFour.
\item On Qwen3-14B the whole effect is \emph{append} (\TypeSynAppendFourteen); \emph{override} never fires.
\item On Llama-3.1-8B every type rises, including \emph{override} (\TypeSynOverrideLlamaEight).
\item \emph{Refuse} fires only on Qwen3-32B (\TypeSynRefuseThirtyTwo) and the two Llama models.
\end{itemize}

\textbf{Natural documents.} Compliance under plain prefill is much higher than on synthetic documents. Qwen3-4B, for example, obeys
the override on Wikipedia documents \TypeNatOverrideFour, against \TypeSynOverrideFour\ on synthetic ones. The two task framings
therefore differ: an explicit notice embedded in an encyclopedic article is apparently more salient than one in a procedure
manual. Against this higher baseline:
\begin{itemize}
\item Qwen3-4B is at ceiling and does not change (\ScaleNatDFour).
\item Packs raise compliance strongly on Llama-3.2-3B (\ScaleNatDLlama) and Qwen3-32B (\ScaleNatDThirtyTwo). Most of this is the
  \emph{append} instruction (Llama \TypeNatAppendLlama; Qwen3-32B \TypeNatAppendThirtyTwo).
\item The increase is moderate on Llama-3.1-8B (\ScaleNatDLlamaEight) and the 4-bit Qwen3-8B (\ScaleNatDEightQ).
\item On Qwen3-8B (\ScaleNatDEight) and Qwen3-14B (\ScaleNatDFourteen) the increase is small and does not survive Holm correction.
\end{itemize}

\textbf{Scale and quantization.} The effect does not decrease monotonically with size. The two largest increases on synthetic
documents are at 4B and 32B, and the smallest at 14B. With one model per size, and 4-bit weights at 14B and 32B, we make no claim
about a trend. Two controls bear on the 4-bit and family questions:
\begin{itemize}
\item The 4-bit Qwen3-8B shows the effect on both datasets, but the magnitudes differ from bf16. It is smaller on synthetic
  documents (\ScaleSynDEightQ\ against \ScaleSynDEight) and larger on natural ones (\ScaleNatDEightQ\ against \ScaleNatDEight).
  Quantization thus changes how large the effect is but is not needed for it, and the 14B and 32B magnitudes should be read with this
  in mind.
\item Llama-3.1-8B, a second Llama model, shows one of the largest increases on synthetic documents (\ScaleSynDLlamaEight), so the
  effect is not specific to Qwen.
\end{itemize}

\textbf{The cache is clean.} No attacker access to the cache is involved: the pack is computed from exactly the visible text.

\item Qwen3-8B, Qwen3-14B, Qwen3-32B and Llama-3.1-8B rise by \IaDEight, \IaDFourteen, \IaDThirtyTwo\ and \IaDLlamaEight.
\item On Qwen3-14B both case types rise: direct harm \IaDHFourteen\ and data stealing \IaDSFourteen.
\item Qwen3-4B rises by \IaDFour; its CI touches zero.
\item Llama-3.2-3B almost never calls the attacker tool in either condition, a floor.
\end{itemize}
With the injection removed, attacker tools are essentially never called, so the increase is caused by the injection. At the
256-token budget, at most \IaTruncMax\% of responses in any cell are truncated.

\textbf{Defenses at the prompt level.} Two defenses leave the increase in place:
\begin{itemize}
\item A system prompt that tells the model never to follow instructions inside documents leaves pack compliance unchanged (Appendix
  Table~\ref{tab:agent}).
\item Spotlighting by datamarking~\citep{hines2024spotlighting} lowers compliance under plain prefill, to at most
  \SpotToneFour\ (Table~\ref{tab:spotlight}). It does not stop the pack. Pack compliance stays at \SpotTthreeFour\ on Qwen3-4B and
  \SpotTthreeEight\ on Qwen3-8B, so the increase is as large as without spotlighting, or larger (\SpotDFour\ and \SpotDEight). On
  Llama-3.2-3B the increase shrinks but remains (\SpotDLlama).
\end{itemize}
We did not test trained defenses such as SecAlign~\citep{chen2025secalign,chen2025metasecalign} under packs.

\subsection{Behavioral localization: the document never saw the request}\label{sec:mechanism}
\textbf{Masking inside an ordinary prefill.} \cond{T1$'$} keeps the true positions and blocks attention from the document to the
conversation, with no pack involved. On its own this raises compliance over plain prefill in 13 of 14 model-by-dataset cells
(Table~\ref{tab:scale}). Examples are \ScaleSynDMaskTextFour\ on Qwen3-4B and \ScaleNatDMaskTextThirtyTwo\ on Qwen3-32B; the
exception is Qwen3-4B on natural documents, which is at ceiling.

\cond{T1$'$} also reproduces the pack closely on five models: \cond{T3}$-$\cond{T1$'$} lies within $\pm 0.08$ (Appendix
Table~\ref{tab:mechanism_all}). As noted in \S\ref{sec:method}, this agreement is expected under relative position encoding, so it
shows that key re-rotation is not an artifact of our implementation. It does not by itself identify a mechanism.

On two models the remaining difference---the size of the position gap between the system prompt and the document---matters:
\begin{itemize}
\item Llama-3.1-8B obeys the pack more than masked text (\ScaleSynDMaskLlamaEight\ on synthetic documents).
\item The 4-bit Qwen3-8B obeys it less (\ScaleSynDMaskEightQ).
\end{itemize}
On both models the masked text is still obeyed far more often than plain prefill.

\textbf{Which edge matters.} Table~\ref{tab:localization} masks only one part of the conversation. On all four models tested, the
result is the same:
\begin{itemize}
\item \textbf{Request visible, call masked.} Compliance stays at the level of plain prefill. Relative to \cond{T1}, it changes by
  \LocSynReqFour, \LocSynReqEight, \LocSynReqLlama\ and \LocSynReqFourteen\ on synthetic documents (Qwen3-4B, Qwen3-8B,
  Llama-3.2-3B, Qwen3-14B). On natural documents the changes are at most 0.09 in either direction.
\item \textbf{Call visible, request masked.} Compliance rises to the level of the pack or above. On synthetic documents the rise is
  \LocSynCallFour, \LocSynCallEight, \LocSynCallLlama\ and \LocSynCallFourteen; on natural documents it is up to \LocNatCallLlama\
  (Llama-3.2-3B).
\end{itemize}
The protective edge is therefore the one from the document to the user's request. A document encoded with sight of the request is
read as material for that request. A document encoded without it is obeyed as if it were an instruction, even when it saw the tool
call that fetched it. This is an intervention on attention, not a correlation, and it accounts for the pack effect without any role
for position.

\textbf{Conversation-shaped prelude.} A pack built after a content-free question and tool call (\cond{T3G}) behaves differently by
model (Appendix Table~\ref{tab:mechanism_all}):
\begin{itemize}
\item On Llama-3.2-3B it removes the effect, and on natural documents it even lowers compliance below text.
\item On Qwen3-4B and Qwen3-8B it leaves a significant excess on both datasets.
\item On Qwen3-14B the excess is small on both datasets.
\end{itemize}
Seeing \emph{a} conversation is not equivalent to seeing \emph{the} conversation, so a generic prelude is not a reliable mitigation.

\textbf{Role confound.} In Qwen's chat template a tool result is a \texttt{user} turn, so a Qwen pack encodes the document as if it
were the first user message. Llama uses a dedicated \texttt{ipython} role and shows the effect as well. This reduces the concern but
does not rule it out, since Llama's pack is still the first non-system turn.

\textbf{Where the model looks.} We run the last prompt token through the model with explicit attention and measure where it
attends (Table~\ref{tab:attention}, Figure~\ref{fig:attn_layers}). This is the position that emits the first answer token.
\begin{itemize}
\item \textbf{Synthetic documents.} On every model the pack raises attention to the injected span, from \AttnInjSynEight\ (Qwen3-8B)
  to \AttnInjSynFour\ points (Qwen3-4B). On four of five models it lowers attention to the user turn; on Qwen3-8B that attention
  rises instead (\AttnUserSynEight).
\item \textbf{Natural documents.} The picture is mixed. Attention to the injected span rises on Llama-3.2-3B, Qwen3-14B and
  Qwen3-32B, is unchanged on Qwen3-4B, whose behavior does not change either, and falls on Qwen3-8B (\AttnInjNatEight), whose
  behavior rises slightly.
\item \textbf{Items that flip.} On Qwen3-4B, Qwen3-8B and Llama-3.2-3B, items that flip to compliance under a pack show a larger
  increase than items that do not (flip $-$ stay \AttnFlipStayFour, \AttnFlipStayEight\ and \AttnFlipStayLlama\ points). On the two
  4-bit models there is no difference. Flips are dominated by synthetic items, so source partly confounds this comparison.
\end{itemize}
Head-averaged attention mass is a coarse, correlational proxy~\citep{hung2025attentiontracker}. Our causal evidence is the
masking and partial-mask interventions above.

\textbf{Boundary recompute.} Recomputing the first or last 16 document tokens changes compliance by at most 0.05 (Appendix
Table~\ref{tab:mechanism}), so seam repair~\citep{li2026notes} is not a defense.

\textbf{Selective recompute.} Deviation-selected recompute reduces the excess as its budget grows (Figure~\ref{fig:sweep}), but the
shape depends on the model:
\begin{itemize}
\item On Qwen3-4B the decline is roughly linear in compute. The excess is still \SweepBfiftyFour\ at \FracBfifty\%.
\item On Qwen3-8B and Llama-3.2-3B most of the reduction happens in the first \FracBfifteen\% of compute. At \FracBfifty\% the
  residual is \SweepBfiftyEight\ and \SweepBfiftyLlama.
\item On Qwen3-14B the decline is slow: the first \FracBfifteen\% does not help at all, and \SweepBfiftyFourteen\ remains at
  \FracBfifty\%.
\item On Qwen3-32B a residual of \SweepBfiftyThirtyTwo\ remains at \FracBfifty\%.
\end{itemize}
At \FracBfifteen\% of compute, deviation-based selection is better than random selection on all three bf16 models, but the
difference is small, and its CI touches zero on two of them (Appendix Table~\ref{tab:mechanism}). On InjecAgent, \FracBfifteen\%
recompute leaves almost the whole increase. The residual over text is \IaResidFourteen\ on Qwen3-14B and \IaResidLlamaEight\ on
Llama-3.1-8B (Table~\ref{tab:injecagent}).

\textbf{Cost.} The latency benefit shrinks with the recompute budget (Figure~\ref{fig:sweep}, bottom). At \FracBfifty\% compute, TTFT
is \TtftTthreeBfivezeroFour\,s against \TtftToneFour\,s for full prefill and \TtftTthreeFour\,s for the plain pack on Qwen3-4B, and
\TtftTthreeBfivezeroThirtyTwo\,s against \TtftToneThirtyTwo\,s and \TtftTthreeThirtyTwo\,s on Qwen3-32B. Our engine recomputes layer
by layer in Python and is not optimized, so absolute times overstate the cost, but the ratio of recomputed tokens does not depend on
the implementation.

\textbf{RAG layout.} When three retrieved documents precede the question, not even full prefill lets them see the question.
Precomputing each chunk then removes only cross-document attention (Appendix Table~\ref{tab:rag}).
\begin{itemize}
\item Qwen3-8B and Llama-3.2-3B never comply under any condition, including full prefill. This floor makes them uninformative.
\item Qwen3-4B, the one model that complies, shows a smaller increase than in the agent layout (\RagDFour, against \InjDFour).
  \FracBfifteen\% recompute brings it within noise (\RagDBFour).
\end{itemize}
This layout differs in role, number of documents and tool use, so it is a contrast rather than a controlled ablation.

\item When the question names every rule, text and pack perform alike (\cond{C3M}$-$\cond{C1M} \WtwoFourDMM). Both then perform

integrated with the task, such as the heading. Llama's \cond{C3M} answers are often truncated (\WtwoLlamaTruncCthreeM\%), so its
\cond{C3M}$-$\cond{C1M} contrast is not interpretable.

\section{Discussion}\label{sec:discussion}
\textbf{A working account.} Text encoded inside a conversation is represented relative to it, as material retrieved for the user's
request, and the model acts on what that request needs. Text encoded without the conversation but read after it is closer to a
standalone instruction. Four results fit this account:
\begin{itemize}
\item the masking control and, most directly, the partial-mask localization;
\item attention on synthetic documents;
\item the per-rule skill results;
\item the RAG contrast.
\end{itemize}

Three results do not fit it cleanly:
\begin{itemize}
\item Chunks with no prelude at all (\cond{R3N}) are \emph{never} obeyed in the RAG layout. Whatever gains authority needs some
  context (here, the system prompt), just not the conversation.
\item A conversation-shaped prelude helps on one model only.
\item On natural documents, attention measurements do not track behavior on Qwen3-8B.
\end{itemize}

\textbf{Implications.}
\begin{itemize}
\item Cache-poisoning attacks~\citep{zhang2026hijackkv,zhu2026r2ecap} call for integrity checks on cached state. Our results show
  that an honestly computed cache can still change model behavior. Whether to reuse context-free KV must therefore also depend on
  where the content came from.
\item Isolating untrusted text in attention, without training, does not act like the trained separation of data and
  instructions~\citep{chen2025struq,chen2025secalign,wu2025ise}. Whether trained defenses survive packs is open.
\item On natural documents packs also lower answer accuracy on most models, because the document is encoded without knowing what
  will be asked. A context-free cache is therefore not a neutral optimization even for trusted content.
\end{itemize}

\textbf{Recommendations.}
\begin{itemize}
\item Reserve context-free reuse, with provenance metadata, for trusted first-party content. Check per model that it does not
  degrade how that content is followed.
\item Prefill untrusted tool output in context whenever it follows the user's request. On some of our models even selective
  recompute of half the tokens leaves a residual.
\item Evaluate reuse features for instruction-following and injection behavior, not only for accuracy and latency.
\end{itemize}

\section{Limitations}\label{sec:limitations}
\begin{itemize}
\item \textbf{Models.} All models are open, at most 32B parameters, from two families, and the two largest are 4-bit quantized.
\item \textbf{Systems.} We do not test production serving stacks (LMCache/CacheBlend or EPIC in vLLM). Our CacheBlend-style engine
  uses one-shot rather than gradual token selection.
\item \textbf{Defenses.} We test prompt-level defenses only, not trained ones such as StruQ or SecAlign.
\item \textbf{Data.} The synthetic documents and skills are templated, and the canary injections are explicit, also in the natural
  documents.
\item \textbf{Agents.} Our InjecAgent variant measures only the first attacker call in a single turn. Multi-step agents (e.g.,
  AgentDojo~\citep{debenedetti2024agentdojo}) and harmful outcomes rather than canaries remain to be tested.
\item \textbf{Skills.} The skill benefit is clear on one model only, and it is matched by system-prompt placement.
\item \textbf{Mechanism.} Our account rests on behavioral interventions and correlational attention measurements, not on a
  circuit-level analysis.
\end{itemize}

\section*{Broader impact statement}
This work identifies a way that a performance optimization can weaken a model's resistance to prompt injection. The vulnerable
configuration requires reusing context-free KV for untrusted content placed after the user's request, which we did not find in
deployed systems. We therefore present it as a design warning, together with the mitigation and its cost. All injections are inert
canaries or the simulated tools of a public benchmark, run against local models. An AI coding assistant was used for
implementation, running experiments and drafting; a script generates every reported number from the released logs.
